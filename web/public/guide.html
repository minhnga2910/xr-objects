Tóm tắt nhanh: repo xr-objects là một dự án Unity (C#, ARCore, MediaPipe) — kết quả build là file .apk cài trên điện thoại Android, không phải website, nên Vercel không thể build hay host nó. Vì vậy bản deploy trên Vercel là một bản web mô phỏng cùng pipeline (camera → nhận diện → context menu → Gemini), còn app Android gốc vẫn build bằng Unity Hub theo hướng dẫn ở phần 03.

01 · Dùng bản web demo

Bản web chạy ngay trong trình duyệt điện thoại, không cần cài đặt. Pipeline giống bản Unity: camera → phát hiện vật thể → neo → chạm để mở menu.

  1. Mở app bằng Chrome hoặc Safari

    Trên iPhone phải dùng Safari (iOS chỉ cho Safari truy cập camera). Trên Android dùng Chrome. Có thể "Thêm vào màn hình chính" để chạy như app.

  2. Bấm “Bật camera” và cho phép quyền

    Nếu bạn từ chối, hãy mở khoá quyền camera trong cài đặt trang web. Không muốn dùng camera? Bấm Tải ảnh lên và chọn một bức ảnh có vật thể.

  3. Bấm “Nhận diện”

    Hệ thống gửi một khung hình cho Gemini, nhận về danh sách vật thể kèm khung bao. Mỗi vật thể được neo ngay trên hình — viền xanh là vật thể do máy phát hiện.

  4. Chạm vào một vật thể

    Menu toả tròn 6 hành động hiện ra quanh vật thể đó, đúng mô hình "chuột phải" của XR-Objects. Chạm ra ngoài để đóng.

  5. Dùng “Tự động” nếu muốn cập nhật liên tục

    Bật Tự động để hệ thống quét lại mỗi 6 giây khi bạn di chuyển camera — gần giống chế độ chạy nền MediaPipe trong app gốc. Tắt đi khi đã đủ vật thể để tiết kiệm pin và quota API.

Đăng ký vật thể thủ công

Đôi khi detector bỏ sót vật thể. Hai chế độ lấy từ bản Unity (nút (1) và (2) trong app gốc):

Nhấn giữ long press

Bật nút Nhấn giữ, rồi giữ ngón tay ~0,5 giây lên vật thể. Một khung nét đứt màu vàng sẽ được đặt tại đó và Gemini sẽ đặt tên cho vùng ảnh này.

Khoanh tròn circle

Bật nút Khoanh rồi vẽ một vòng quanh vật thể. Hệ thống lấy hộp bao của nét vẽ và đăng ký vùng đó. Phù hợp với vật thể méo hoặc nằm cạnh vật khác.

03 · Build app Android gốc (Unity)

Đây là phần không thể làm trên Vercel. Cần Unity Hub + Unity Editor (bản AR Foundation tương ứng) và Android SDK/NDK trên máy tính của bạn.
  1. Clone repo và mở bằng Unity Hub

    git clone https://github.com/minhnga2910/xr-objects rồi mở thư mục XRObjects/ trong Unity Hub (không phải DemoHeadset/ nếu bạn muốn bản ARCore cho điện thoại).

  2. Chuyển target platform sang Android

    File → Build Settings → Android → Switch Platform. Kiểm tra Scripting Backend = IL2CPP, Minimum API Level = Android 7.0 (API 24), Target Architectures = ARMv7 + ARM64.

  3. Mở scene và đặt Gemini key

    Mở Assets/XRObjects/SceneXRObjects, đảm bảo đây là scene duy nhất trong "Scenes In Build". Lấy key ở aistudio.google.com/app/apikey, rồi dán vào biến apiKey trong Assets/XRObjects/Scripts/ImageQuery.cs.

    Lưu ý bảo mật: key nằm ngay trong APK. Chỉ dùng cho thử nghiệm cá nhân, đừng phát hành công khai.

  4. Build APK và cài lên máy

    Build & Run, hoặc xuất APK rồi adb install -r -d -g duong_dan.apk. Cấp quyền camera, vị trí và bật WiFi.

  5. Thao tác trong app

    Bấm nút (1) để bắt đầu nhận diện (MediaPipe Object Detector chạy trên máy), rồi chạm vào vật thể để mở context menu. Bấm (2) để tắt detector khi đã nhận đủ vật thể — app sẽ mượt hơn mà vẫn tương tác được với các vật thể đã neo.

Nếu gặp lỗi Multiple precompiled assemblies with the same name Google.Protobuf.dll, xoá một trong hai file, ví dụ bản trong /Editor/Scripts/Internal/Analytics. Chi tiết đầy đủ nằm trong README của repo.

04 · Tự deploy lên Vercel + Supabase

Toàn bộ mã nguồn bản web nằm trong thư mục web/ của repo này. Không cần bước build — thư mục web/public được host tĩnh, còn web/api/*.js chạy dạng serverless function giữ kín API key.

Cấu trúc thư mục

web/
├── vercel.json          # cấu hình host tĩnh + functions
├── public/              # index.html, app.js, styles.css, guide.html
├── api/
│   ├── _gemini.js       # helper gọi Gemini (không phải route)
│   ├── config.js        # trả URL + publishable key của Supabase
│   ├── detect.js        # ảnh → danh sách vật thể + bbox
│   ├── label.js         # đặt tên thương hiệu cho vật thể
│   ├── describe.js      # tóm tắt thông tin
│   ├── ask.js           # hỏi đáp nhiều lượt
│   └── compare.js       # so sánh nhiều vật thể
└── supabase/schema.sql  # tạo bảng + RLS

Biến môi trường

BiếnBắt buộcDùng để
GEMINI_API_KEYnên cóNhận diện, đặt tên, hỏi đáp. Không có → app tự chuyển chế độ demo với dữ liệu mẫu.

Deploy bằng Vercel CLI

# trong thư mục gốc repo
cd web
npx vercel link          # chọn team minhnga2910
npx vercel env add GEMINI_API_KEY production
npx vercel env add SUPABASE_URL production
npx vercel env add SUPABASE_ANON_KEY production
npx vercel --prod

Vào Vercel → Project → Settings → Root Directory và đặt thành web nếu bạn deploy từ GitHub. Framework preset: Other, Build Command: để trống, Output Directory: public (đã khai báo sẵn trong vercel.json).

Hoặc deploy qua GitHub

  1. Push repo lên GitHub.
  2. Vercel → Add New → Project → chọn xr-objects.
  3. Root Directory = web, Framework = Other.
  4. Thêm 3 biến môi trường ở trên → Deploy.

Tạo database Supabase

  1. Tạo project mới trên supabase.com (region Southeast Asia (Singapore) cho người dùng Việt Nam).
  2. Mở SQL Editor, dán nội dung web/supabase/schema.sql và chạy.
  3. Vào Project Settings → API, copy Project URL và anon public key, dán vào 2 biến môi trường của Vercel.
  4. Redeploy. Trong app, mở Cài đặt — dòng Supabase phải hiện "Đã kết nối".
Policy trong schema đang mở hoàn toàn (using (true)) để bản demo dùng được ngay mà không cần đăng nhập. Nếu triển khai cho người dùng thật, hãy thêm Supabase Auth và đổi policy thành auth.uid() = owner_id, đồng thời thêm cột owner_id. Đừng lưu dữ liệu nhạy cảm với policy mở.

05 · Cấu trúc database

Bản web ghi lại đúng những gì app Unity giữ trong scene, để sau này có thể đồng bộ giữa hai bên:

BảngCột chínhÝ nghĩa
sessions device, user_agent Mỗi lần mở app là một phiên; dùng để nhóm vật thể.
objects label, category, confidence, bbox, source, metadata Vật thể đã neo. bbox là toạ độ chuẩn hoá 0–1 nên đổi kích thước màn hình vẫn đúng. source ∈ gemini / demo / mediapipe (engine nhận diện); cách đăng ký (detector / longpress / circle) lưu trong metadata.method.
notes object_id, body, anchor Ghi chú không gian dán lên vật thể.
timers object_id, kind, duration_seconds, started_at Hẹn giờ / bấm giờ bắt đầu từ context menu.
saved_items object_id, label, list Danh sách "lưu để sau".
object_actions object_id, action, input, output, payload Nhật ký mọi hành động (tham số model, độ trễ) — dùng để đo chất lượng prompt. action ∈ info / ask / note / timer / stopwatch / save / compare.
object_feed view View tổng hợp cho panel "Nhật ký scene".

Ví dụ truy vấn

-- Vật thể nào được tương tác nhiều nhất?
select o.label, o.category, count(a.id) as actions
from objects o
join object_actions a on a.object_id = o.id
group by o.label, o.category
order by actions desc
limit 10;

-- Độ trễ trung bình của Gemini theo từng loại hành động
select action,
       round(avg((payload->>'latencyMs')::numeric)) as ms
from object_actions
where payload ? 'latencyMs'
group by action;

06 · Câu hỏi thường gặp

Vì sao không deploy thẳng repo này lên Vercel?

Vì repo chứa dự án Unity (C#) kèm thư viện native ARCore/MediaPipe và model .tflite. Sản phẩm của Unity là file APK/AAB chạy trên Android — một hệ điều hành, không phải môi trường serverless. Ngoài ra repo rất nặng (~790 MB) với thư viện nhị phân, không phù hợp giới hạn build của Vercel. Bản web trong web/ tái hiện đúng luồng tương tác để bạn trải nghiệm và để dùng làm landing page cho dự án.

Bản web có dùng AR thật không?

Không. Trình duyệt không có plane tracking/depth như ARCore. Bản web mô phỏng phần tương tác: vật thể được neo trong không gian ảnh (normalized bbox) và menu toả tròn quanh vật thể. Muốn AR thật (bám vào bàn, đi vòng quanh vật thể) thì dùng bản Unity trên máy Android.

Camera không mở / báo lỗi quyền

  • Trang phải chạy trên HTTPS (Vercel mặc định có) — http:// sẽ bị chặn camera.
  • iOS: chỉ Safari hỗ trợ getUserMedia; Chrome trên iOS không mở được camera.
  • Kiểm tra icon 🔒 trên thanh địa chỉ → quyền Camera → Allow, rồi tải lại trang.
  • Vẫn không được: dùng nút Tải ảnh lên để thử toàn bộ luồng tương tác.

Chưa có Gemini API key thì sao?

App vẫn chạy: nó tự chuyển chế độ demo với 4 vật thể mẫu và nội dung mẫu, để bạn xem được toàn bộ UI và luồng menu. Thêm GEMINI_API_KEY vào Vercel rồi redeploy là AI hoạt động thật.

Tốn phí bao nhiêu?

Gemini 2.0 Flash có hạn mức miễn phí hằng ngày; mỗi lần nhận diện = 1 request kèm 1 ảnh JPEG ~720px. Bật Tự động sẽ gọi API mỗi 6 giây nên hãy tắt khi không cần. Supabase và Vercel đều có gói free đủ dùng cho demo.

Có dùng được trên desktop không?

Được — mở bằng Chrome trên máy tính, giao diện sẽ đặt khung điện thoại bên trái và phần giới thiệu bên phải. Webcam máy tính hoạt động bình thường.
